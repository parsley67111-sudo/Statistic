# Мои тикеты — статистика смен

Небольшое браузерное приложение для учёта выполненных тикетов и сравнения с нормой **450 тикетов за смену**.

## Возможности
- Добавление смены по дате и количеству решённых тикетов.
- Разница с нормой для каждой смены и нарастающим итогом за месяц.
- Сводка по месяцам, среднее за смену, процент выполнения плана.
- Редактирование и удаление записей.
- Настройка дневной нормы.
- Экспорт CSV для Excel, резервная копия и восстановление через JSON.
- Адаптивная вёрстка для телефона и компьютера.

## Размещение на GitHub Pages
1. Сделайте репозиторий публичным (или используйте поддерживаемый платный тариф Pages для приватных репозиториев).
2. Откройте **Settings → Pages**.
3. Выберите **Deploy from a branch**, **main** и **/(root)**, сохраните.
4. После публикации сайт доступен по адресу **https://parsley67111-sudo.github.io/Statistic/**.

## Важно о хранении
Это полностью статический сайт. Все записи хранятся в `localStorage` **конкретного браузера и устройства**. GitHub хранит код, а не ваши данные. При очистке данных сайта записи исчезнут; экспортируйте JSON для резервного копирования и переноса на другое устройство. Синхронизация между устройствами не предусмотрена.
